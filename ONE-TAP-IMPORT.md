# The Brief v7 — quick clipboard import

Replace **index.html**, **app.js**, and **sw.js** in your existing GitHub Pages repository. Commit and allow Pages to deploy. Open the app again on your iPhone (if the previous version persists, open the GitHub Pages URL in Safari and refresh).

## Daily use
1. Open your daily ChatGPT briefing and choose **Copy** on the *whole* assistant response.
2. Open The Brief → **Today**.
3. Tap **Import copied briefing**. Allow **Paste** if iOS asks.
4. You will have five complete cards; the original full text is preserved and the archive updated.

## If clipboard access is blocked
Some versions/settings of iOS prevent installed web apps from reading the clipboard directly. The app automatically opens Settings with the normal paste field focused. Long-press and select **Paste**, then **Import briefing**. No API key or Shortcut required.

## Important
The workflow is **one tap in The Brief after copying**; it cannot access ChatGPT messages before you copy them. Imports are stored on this device. Export backups occasionally from Settings. If parsing fails, the existing five articles and archive are not replaced. Exact-on-device iOS behavior has not been verified.
